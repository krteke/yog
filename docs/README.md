# Advanced reference

These documents describe machine-readable formats and runtime behavior for scripting, result analysis, and further development. For everyday commands, see the [CLI guide](../crates/yog-cli/README.md).

- [Report JSONL](report.md): task outcomes, reasons, encoding settings, source media facts, and measurements.
- [State JSONL](state.md): settings, file fingerprints, and the latest task states needed for recovery.

A complete configuration example is available in [config.example.toml](../crates/yog-cli/config.example.toml).

To preview chart styling, use the [runtime chart preview example](../crates/yog-runtime/README.md).
