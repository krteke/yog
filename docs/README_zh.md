# 高级参考

这里记录机器可读格式和运行语义，供脚本集成、结果分析和二次开发使用。日常命令见 [CLI 使用指南](../crates/yog-cli/README.md)。

- [Report JSONL](report.md)：任务结论、原因、编码设置、源媒体事实和测量数据。
- [State JSONL](state.md)：恢复所需的参数、文件指纹与任务最新状态。

全部配置示例位于 [config.example.toml](../crates/yog-cli/config.example.toml)。

仅预览曲线样式，可使用 [runtime 图表预览示例](../crates/yog-runtime/README.md)。
